# Chrome Web Store listing — Inkspect

## Name

Inkspect — Responsive Preview & Visual Feedback

## Summary (max 132 characters)

Responsive preview with synced device frames, visual feedback tools and a live CSS editor — right on the page.

## Description

Inkspect turns the page you are working on into a responsive design studio: preview it in multiple device viewports at once, keep every frame perfectly in sync, edit CSS live, and collect visual feedback exactly where it belongs — on the page itself.

No external tools, no uploads, no account. Open it on any page with one click.

SYNCED DEVICE PREVIEWS
• See the current page in phone, tablet and desktop viewports side by side
• Scrolling, clicks, typing, hover states (JS and CSS :hover, even inside Shadow DOM) and link navigation are mirrored across all frames in real time
• A navigation watchdog keeps every frame aligned — including SPA routing via pushState
• Add, rotate and remove devices freely; zoom the whole grid
• Define your own viewport sizes — your device setup, custom sizes and zoom are remembered across sessions

VISUAL FEEDBACK, RIGHT ON THE PAGE
• Element picker: hover to highlight DOM elements, click to capture them with a readable label
• Comment pins, freehand drawing, rectangles, ellipses, arrows and text notes — pins, picked elements and shapes take an optional comment
• Guide lines across the full width or height — drag a second one to measure the gap in pixels, or type the target value into the note
• Move and resize your own markings by their outline; element picks stay locked to the DOM box they measured
• Markings stick to the content while you scroll and stay bound to page + device viewport
• A floating tool bar that snaps to the left edge or the bottom — or sits docked under the grid
• A tidy panel groups all feedback per page and per device, with sizes and spacings right next to each item
• Check items off as you fix them — done markers dim on the page, badges count what is still open

SHARE IT — WITHOUT A SERVER
• All feedback of a page is compressed and encoded directly into the URL hash
• Anyone with Inkspect installed opens your link and sees the markings live on the page
• Or copy everything as clean, structured text for tickets and chat

ANNOTATED SCREENSHOTS, ONE CLICK
• Download annotated full-page screenshots of every page that has open feedback — one image per device viewport, the whole page, not just the visible part
• All drawings are included, and every written note is rendered right at its marker, so the images speak for themselves in tickets, chats and reviews

LIVE CSS EDITOR
• Edit the page's stylesheets in a full CodeMirror editor — cross-origin sheets included
• Changes apply instantly across all device frames and survive reloads
• Reset any sheet back to the original with one click

WORKS WITH STUBBORN PAGES
• Pages that refuse to be embedded (X-Frame-Options / frame-ancestors) can still be previewed via an explicit opt-in — scoped to the current tab and its preview frames only

PRIVACY
Inkspect stores your feedback locally in your browser. Nothing is uploaded anywhere — shared links carry the data inside the URL itself.
